# Design Plan — Powercraft Rebuild

## Color tokens
| Token | Hex | Role |
|---|---|---|
| `--ink` | `#0F0E1E` | Page background (deep indigo-black) |
| `--panel` | `#17162C` | Card/section surfaces |
| `--violet` | `#7C5CFC` | Power Apps node / primary accent |
| `--sky` | `#4C9AFF` | Power Automate node |
| `--teal` | `#22D3B4` | Power BI node |
| `--amber` | `#FFB454` | Copilot node / CTA color (used sparingly) |
| `--text` | `#F3F1FF` | Primary text on dark |
| `--mute` | `#9C97BE` | Secondary text |

## Type
- Display: **Space Grotesk** (headlines, nav, stat numbers)
- Body: **Inter** (body copy)
- Mono: **IBM Plex Mono** (counters, FAQ numbering, card eyebrows)
